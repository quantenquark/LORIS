## LoRaWAN applications for ELV devices  / ELV-BM-TRX1 code templates

A possible enhancement for the modular ELV ecosystem would be a hybrid device combining the ELV-BM-TRX1 field strength tester with a GPS module. The current setup already allows evaluation of LoRa signal quality from gateways and network nodes. By adding GPS coordinates to each measurement, the device could become a powerful tool for generating coverage maps and collecting data for TTN Mapper. This would allow users to perform drive tests or walking surveys and automatically relate RSSI/SNR values to specific geographic locations, simplifying network optimization considerably.
